# 发布材料范围

本仓库分享原创教程、配置示例和独立的只读校验工具。公开内容以仓库中的文件为准；本机完整维护记录不在发布范围内。

本教程允许的文件类型为原创 Markdown、配置示例、独立的只读校验脚本和 MIT 许可文本。

不要把本机整个游戏目录加入 Git。游戏 EXE、DLL、DAT、DRS、修改后的原生程序/界面、存档、录像、玩家文件和原始本机日志不属于此发布草稿。

旧 AoE2Wide 的源码、patch 表以及直接衍生的 Python/C# 未纳入草稿，等待明确再发布许可。第三方工具通过作者项目链接获取；其许可不被本仓库的 MIT 取代。

公开材料使用通用路径说明，未写入个人邮箱、用户名、绝对安装路径、GitHub 登录信息或安全策略标识。

分享时清楚区分已验证结果和适用范围：一份经典 1.0 构建的单机实测，不保证所有版本、所有扩展包、联机和长期运行。应用控制拦截应使用受支持的处理方式；本教程没有关闭保护或绕过执行限制的代码。
